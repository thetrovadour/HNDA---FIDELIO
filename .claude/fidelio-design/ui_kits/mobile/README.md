# FIDELIO Mobile App — UI Kit

High-fidelity recreation of the FIDELIO H-Wallet mobile app (packages/mobile or app/ in source).

## Components
- `StatusBar.jsx` — iOS status bar simulation
- `LoginScreen.jsx` — ACCEDER screen with CATR logo + PIN-less entry
- `HomeScreen.jsx` — balance card (shimmer gold), quick actions, recent activity
- `SendScreen.jsx` — send CATR / HNL flow mock
- `PhoneFrame.jsx` — iPhone-ish bezel wrapper with navigation

## Screens
`index.html` — interactive click-thru: Login → Home → Send → back.

Dark surface `#0C1018`, gold `#C9A84C`, text `#F1F5F9`, card radius `12px`.
