# HNDA Web — Marketing Site Kit

High-fidelity recreation of the hnda.io marketing site (packages/web in the source repo). Next.js → static HTML + inline JSX for this kit.

## Components
- `Nav.jsx` — fixed glass top nav with HNDA stencil wordmark + network CTAs
- `Hero.jsx` — full-viewport hero with radial glow, eyebrow label, giant H1, primary CTA
- `MissionCards.jsx` — 3-up pillar cards ("Sovereignty as strategy" etc.)
- `ProductGrid.jsx` — product card list with Live/Coming Soon status
- `Footer.jsx` — minimal footer with links + location

## Screens
`index.html` — homepage composed from all components.

Built against: colors_and_type.css (root), fonts via Google Fonts import in CSS.
